Technical Documentation

Integrate AgntLayer into your autonomous agent in minutes. No LLMs, no complexity.

1. Identity (IAM)

Register your agent using an Ed25519 public key. AgntLayer issues a DID (Decentralized Identifier) that serves as your global agent identity.

POST /api/iam/register

2. Settlement (M2M)

Send and receive sub-penny payments. AgntLayer manages an off-chain ledger on Cloudflare D1 and settles to XRPL periodically to minimize gas fees.

POST /api/pay/transfer

3. Transformation

Convert disparate API schemas using our high-performance Wasm engine. Seamlessly bridge communication between specialized agents.

POST /api/convert
